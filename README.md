# Mockup Magic Wand

मुझे एक tool बना के दो जो mockups generate कर सके। ठीक है। हम picture upload करें और वो उसके 10 mockup generate कर सके। ठीक है। तो एक ऐसा tool बना के दो। मैं तुम्हें samples भेज रही हूँ कि किस तरह से mockup होने चाहिए। ठीक है। सारी details और samples वगैरह भेज रही हूँ। तो तुम मुझे उस तरह का एक tool बना के दो जो mockups generate कर सके। ठीक है।

सिर्फ एक original image upload हो और 10 mockup generate हो जाए। ठीक है। multiple generate कर सके बंदा एक के बाद और भी generate कर सकता है। ठीक है, मैं तुम्हें भेज रही हूँ किस तरह के mockup generate

तुम देख सकते हो जो पहली image मैंने attach की है वो एक original image है। वो मिसाल के तौर पर for example अगर इस तरह की कोई image upload होती है तो mockups किस तरह के generate हो गए। आगे जितनी images हैं वो सारे mockups की images हैं। ठीक है। उस तरह के mockups generate हो जाए 10। तो यह हो, समझ आ गई। अच्छा इसको SPA React Router में कर दो। ठीक है। और TanStack वाला use नहीं करना और इसको SPA React Router client side में develop करना। ठीक है। यह मुझे tool चाहिए web page चाहिए एक जिसके ऊपर यह सारी चीज हो सके।
